Project Caelus

Structures Member / Developer Oct 2024 – Mar 2025

Helping build one of the first high-school-launched liquid-fueled rockets.

The mission

Caelus is a student effort to design, build, and launch a liquid-fueled rocket — a class of vehicle almost no high-school team attempts because of how hard the plumbing, structures, and testing are.

What I worked on

  • CADded and built test stands in Fusion 360 for pre-launch testing.
  • Designed several nose cones — including ogive and conic styles — across multiple rocket designs.
  • Ran several cold-flow tests to validate the feed system.
  • Worked toward building an environment in which to run a static-fire test.

Liquid engines are unforgiving — every joint, tolerance, and test procedure has to be right before anything ever fires. That pressure is exactly what made the structures work so good to learn on.
